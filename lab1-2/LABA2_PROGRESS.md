# Лабораторная работа №2 — этап 2

## Реализовано
- Основным хранилищем GUI теперь является `BstBookStore`; `ObservableList<Book>` используется только как проекция для `TableView`.
- Добавлены `clear()` и `inOrderBooks()` для замены набора при импорте и получения упорядоченного представления.
- Таблица отображает книги в порядке названий, полученном inorder-обходом BST.
- Добавление, редактирование и удаление выполняются через BST.
- При редактировании ключа (названия) узел удаляется по старому ключу и вставляется заново после изменения объекта через сеттеры. При конфликте названия старые значения восстанавливаются.
- CSV-загрузка сначала строит временное дерево, затем заменяет основное; повторяющиеся названия отклоняются с пояснением.
- CSV-сохранение получает записи из inorder-обхода дерева.
- В главное окно встроен JavaFX Canvas; он перерисовывается после изменения данных.
- Добавлен поиск по названию с подсветкой посещённых узлов и выбором найденной строки в таблице.
- Добавлен тест inorder-проекции и очистки дерева.

## Остаётся для лабораторной №2
- Генерация заданного количества книг.
- Фоновая загрузка CSV через `javafx.concurrent.Task` с прогрессом (минимум).
- Для среднего уровня: фоновая генерация с отменой и замеры времени на 10^4 и 10^5 элементов.
- При необходимости — дополнительные элементы UI для диапазона и K последних книг (сами методы BST уже реализованы).

## Этап 3 — генерация и асинхронная загрузка
- Добавлен `BookGenerator`: генерирует заданное число валидных `Book` и `Textbook` с уникальными в пределах набора названиями и ISBN.
- В интерфейс добавлена команда «Сгенерировать книги» с вводом количества (1–100000).
- Генерация выполняется в JavaFX `Task` в фоновом потоке; отображаются прогресс и текст состояния.
- Загрузка CSV переведена на JavaFX `Task`. Сериализатор сообщает долю обработанного файла, а интерфейс показывает ProgressBar.
- CSV сначала полностью разбирается и строится во временном BST в фоне; основное дерево заменяется только после успешного завершения задачи.
- Добавлены тесты генератора: количество, уникальность названий/ISBN, валидность и проверка границ.
